# Trademark Policy

> **SwarmAI** is a trademark of **Soumya Chakraborty**. This policy governs how you may use the SwarmAI name, logo, and related brand assets.

---

## Quick Summary

| You can… | You cannot… |
|----------|-------------|
| Mention SwarmAI in blog posts, tutorials, or reviews | Release a modified build under the SwarmAI name |
| Link to the official SwarmAI GitHub repo | Use the SwarmAI logo to promote another product |
| Fork the repo for personal learning and contribution | Register confusingly similar domain names |
| Use the name to refer to the official app | Create a SaaS or hosted version called SwarmAI |
| Submit pull requests to the official repo | Sell modified builds as "official" SwarmAI |

---

## The Code Is MIT. The Marks Are Not.

SwarmAI's source code is released under the [MIT License](LICENSE). That license covers the software — it does **not** grant any right to use the SwarmAI name, logo, or brand elements. The SwarmAI name and the bee/honeycomb icon are **trademarks** owned by Soumya Chakraborty.

This distinction is important: MIT gives you freedom to use, modify, and distribute the **code**. Trademark law protects the **identity** of the product.

---

## Trademarks Covered

This policy applies to:

- The word **SwarmAI** in any form (stylised, stylized, spaced, combined with other words)
- The **bee icon** used as the app's primary logo
- The **honeycomb motif** as a brand element
- Any visual identity that is recognisably derived from SwarmAI's design language
- Domain names, social media handles, or app store listings using the SwarmAI name

---

## Permitted Uses

You are welcome to:

### 1. Reference SwarmAI

Use the SwarmAI name and logo to refer to the official app, project, or website in articles, blog posts, videos, presentations, and tutorials.

**Example:** *"I use SwarmAI to manage my coding agents."*

### 2. Fork for Learning & Contribution

Fork the repository, study the code, experiment locally, and contribute improvements back via pull request.

### 3. Distribute Unmodified Builds

Share the official, unmodified SwarmAI `.dmg` as provided on the [Releases](https://github.com/soumyachk101/SwarmAI-Release/releases) page, without modification.

### 4. Use the Name in Compatible Projects

If your project works *with* SwarmAI (a plugin, integration, or companion tool), you may use the SwarmAI name to describe that relationship — as long as it is clear your project is not the official SwarmAI app.

---

## Prohibited Uses

You may **not**:

### 1. Release Modified Builds Under the SwarmAI Name

If you fork SwarmAI and produce a modified build, you **must** rename it and replace the icon. You cannot ship it as "SwarmAI" or with the SwarmAI branding.

**Required for forks:**
- Rename the app (do not call it SwarmAI)
- Replace the app icon with an original design
- State clearly in your README that your build is unofficial and not affiliated with Soumya Chakraborty

### 2. Create Confusingly Similar Products

Do not release a product with a name, logo, or UI that is likely to be confused with SwarmAI.

### 3. Hold Out as Official

Do not imply that your fork, modification, or derivative work is the official SwarmAI product, is endorsed by Soumya Chakraborty, or is affiliated with the SwarmAI project.

### 4. Register Brand Assets

Do not register the SwarmAI name, logo, or related domains in any jurisdiction.

### 5. Commercialise Without Permission

You may not use SwarmAI branding to sell a product, service, or SaaS that is not the official SwarmAI app.

## Fork & Build Checklist

If you fork SwarmAI and build your own version:

- [ ] Rename the app (do not use "SwarmAI")
- [ ] Replace the app icon with your own
- [ ] Remove or replace the Liquid Glass branded splash
- [ ] Update the `CFBundleName` and `CFBundleDisplayName`
- [ ] Add a clear disclaimer to your README
- [ ] Do not publish to the App Store under the SwarmAI name
