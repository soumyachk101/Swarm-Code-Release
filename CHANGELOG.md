# Changelog

All notable changes to SwarmAI are documented here.

## [1.1.2] - 2026

### Added
- Model search across all providers in real time
- Provider switching in running chats without losing context

### Fixed
- Eliminated all remaining compiler warnings
- Performance improvements and bug fixes

## [1.0.0] - 2026

### Added
- 8 agent providers: Codex, Claude, Cursor, OpenCode, Grok, Antigravity, DeepSeek, Meta
- Hydra: parallel agent delegation with isolated worktrees
- 26 tinted-glass themes
- Streaming replies with live diff per turn
- Inline approvals and follow-up queuing
- Reasoning slider (Fast to Maximum)
- Built-in terminal per thread
- Native macOS interface with Liquid Glass design
- Zero telemetry, MIT licensed
